# 读、缓存与 Spill

读路径先固定要读取的文件版本和布局，再为每个范围选择来源。来源可以是本地持久副本、远端副本、验证缓存或可选外部 spill。

## 固定版本读

DFS 读已提交内容时必须绑定 `FileVersion`、长度和布局。普通 open 不是永久快照，但跨挂载可见性遵守 close-to-open；一旦读计划固定，就不能混入另一个版本的 chunk。

## 验证缓存

验证缓存可以加速读，但只有经过校验并在 Meta 中提升后才算持久副本。缓存淘汰不能删除唯一持久副本；读缓存命中也不能跳过权限和版本检查。

## Spill

外部 spill 是可选冷容量。写入外部对象后仍要校验并由 Meta 提交，才可作为读来源。当前迁移前收尾不把 spill 作为可试用版本前置条件。
