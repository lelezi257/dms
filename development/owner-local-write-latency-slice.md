# Ordinary OwnerFs local small write: one independent case

This G2.10 slice reuses the frozen f03 product / 7bfc trial package on existing Linux B ext4. Both workspace bind switches remain OFF. No Rust, dependency or VM configuration changes.

Before startup, the external contract fixes 64MiB per new file, 1MiB blocks, concurrency 1, byte 97, one warmup pair and five measured pairs with alternating Owner/Moose order. Each task creates a previously absent file with O_CREAT|O_EXCL, performs 64 pwrite calls, fdatasync and close. The task clock includes open, thread setup, writes, join, fdatasync and close. Each independently measured operation interval covers pwrite plus count validation; it excludes the file barrier. Record the separate barrier_ns and every sorted operation interval. Use CLOCK_MONOTONIC and sorted[floor(N*p/100)] quantiles, pool 320 measured operations per target, exclude warmup, and freeze p95 before the run.

After the timed task, fsync the parent directory and verify full content SHA, length, EOF and mode 0600. Retain all twelve files and results. The Owner Home and official MooseFS master/chunk/client are local to B. Check CREATE/KEEP one-copy policy, local Home identity, one connected chunk server and one VALID physical Moose chunk for each file.

There is no before-create mincore observation: the probe initializes that field to zero because the file does not exist. Record mincore after verification without calling the initialized zero a cold-cache measurement. Backing cache comparability and MooseFS strong durable-ACK qualification are still missing. This slice may complete functionality and retain diagnostic throughput, p50/p95/p99 and barrier times; it cannot pass formal performance. The final target remains throughput >=1.2 times matched MooseFS and independently measured p95 <=0.8 times, both required.
