# Orderly restart: preserve command records and archive private roots safely

2026-10-07. Pre-execution addendum to [rootfs repair](native-rootfs-restart-repair.md), original SHAc0762fbc050d1c582c518295be345634f58cf745a3f4a6087ca416a4b373015c; do not modify that contract or historical results.

Read-only tool review found a second normal-restart product incompatibility: `Driver::new` resets sequence0 while `run_recorded` uses create_new for stdout/stderr, and normal shutdown retains command-0001 artifacts. A second controller would collide before runtime invocation. This is supported by fixed source plus retained command artifacts; no live second-start FAIL is claimed. The original tool-review FAIL and its withdrawn suggestion to move command files remain immutable. Do not archive by moving/deleting existing live control records just to pass.

The narrow first-party repair continues numbering from the largest existing owned command artifact number, preserving all prior record bytes. Scan only recognized decimal command stems/suffixes without following links; reject overflow or ambiguous malformed command artifacts safely. Initialize under controller ownership and clean up newly created lock/socket if initialization fails. Use checked increment before new output creation; do not relax nonempty-runtime-state/adoption guards. Focused Linux tests must prove retained partial/full records select a noncolliding next stem, existing bytes remain unchanged and overflow fails safely. This remains in native_workspace.rs, with no third-party changes.

Per-container private runtime rootfs copies contain runc device/link entries. All maintained native harness modes must use the same safe evidence archiver: preserve each exact owned OCI runtime-root tree in place, publish complete lstat/regular-file hash/link target/device metadata index, archive regular command/config/log/lifecycle records, and never follow/copy devices or unknown roots. Only skip a runtime-root subtree after validating its exact control bundle/OCI path; unknown symlink/nonregular archive inputs fail explicitly. Preserve old archive/read-binding guard results; only new affected archiver/numbering guards run. Readback evidence must identify the new native-call's exact argv/actual exit/stdout, not an old identical shell command.

No product run occurs before the combined rootfs/record fix and tools pass review, Linux source gate, new package identity and one final admission. The frozen two-phase confirmed-data restoration criteria, capacity limits, default OFF and deferred scopes are unchanged.
